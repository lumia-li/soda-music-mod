# soda-music-mod

汽水音乐 Windows 桌面版的功能增强补丁。通过 `resources/app` 目录部署 + 主进程 CDP 注入实现，不修改 `app.asar` 内容，可随时还原。

非官方修改，与汽水音乐官方无关。

## 功能

- 播放倍速 0.5x - 3.0x，支持变速不变调，`Alt + 方向键` 调整
- 睡眠定时器、滚轮切歌、音量区滚轮调音量
- 播放页环形频谱，颜色跟随封面
- 任务栏播控：MusicBar 外观、高潮点、小键盘 `4` / `6` 调进度（最小化后可用）、内嵌 MiSans 字体
- 背景模式：原样 / 黑底 / 透明
- 歌单、收藏、历史播放页的歌曲搜索框
- 隐藏不可播放曲目、评论图片查看器、侧边栏品牌名、窗口圆角

## 使用

需要 Windows 与 Node.js 18 以上。

```bash
node deploy-appdir.mjs
```

脚本会自动查找安装目录；找不到时手动指定：

```bash
node deploy-appdir.mjs --res "X:\你的路径\Soda Music\版本号\resources"
```

还原：

```bash
node deploy-appdir.mjs --restore
```

可选：把 `misans.woff2` 放在项目根目录，作为任务栏播控的字体。

本项目只在作者本机的一个版本(3.8.0)上调试过，没有做跨版本适配，客户端升级后部分功能可能失效。
